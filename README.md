# 📦 我的安卓安装包

所有我做的 Android App 的安装包都放在这里，用手机 GitHub App 打开这个仓库就能下。

## 📲 手机上怎么下载

**方法一（最快）**：看下面的表，点「下载」那一列 → 允许「未知来源」→ 装上。

**方法二**：点仓库下方的 **Releases**（发布）→ 点进去 → 点文件名（`.apk`）→ 下载。

> ⚠️ 装之前如果手机里有同名旧版，先卸载。签名不同的包无法覆盖安装。
